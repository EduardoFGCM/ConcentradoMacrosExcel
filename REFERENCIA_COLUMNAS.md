# TABLA DE REFERENCIA DE COLUMNAS - HOJA CONCENTRADO

## Patrón de Columnas (Se repite cada 4 columnas)

Cada grupo de materiales tiene 4 columnas:
1. **Material** (Descripción del material - **AUTO-GENERADO con fórmulas**)
2. **Referencia** (Código de referencia - **AUTO-GENERADO con listas desplegables**)
3. **Cantidad** (Cantidad consumida - **MANUAL** - Descuenta inventario)
4. **Lote** (Número de lote - **MANUAL** - Requerido antes de cantidad)

> **NOTA IMPORTANTE:** Las columnas de Material y Referencia se llenan automáticamente mediante fórmulas y listas desplegables. El usuario solo debe completar manualmente **Cantidad** y **Lote** para el control de inventario.

## Notas Importantes

1. **Total de grupos en Concentrado:** 30 grupos (del 1 al 30)
2. **Primera columna útil:** Q (columna 17)
3. **Última columna útil:** EF (columna 136)
4. **Total de columnas por grupo:** 4 columnas
5. **Total de columnas utilizadas:** 120 columnas (17-136)

### Control de Inventario (Columnas Manuales)
6. **MATERIAL y REFERENCIA:** Auto-generadas con fórmulas/listas - NO editar manualmente
7. **CANTIDAD y LOTE:** Entrada manual del usuario para control de inventario

### Navegación con Enter (solo para columnas manuales)
8. **Desde CANTIDAD → Salta +1 al LOTE del mismo grupo**
9. **Desde LOTE → Salta +3 a la CANTIDAD del siguiente grupo**
10. Esto optimiza la captura manual evitando las columnas auto-generadas

### Validaciones de Inventario
11. **No se permite CANTIDAD sin LOTE** - Error y se revierte
12. **Al cambiar LOTE con cantidad existente** - Devuelve inventario y limpia cantidad
13. **Al ingresar CANTIDAD** - Descuenta del inventario (valida disponibilidad)
14. **Al reducir/borrar CANTIDAD** - Devuelve al inventario
15. **No se puede editar si no hay REFERENCIA** - Las referencias son auto-generadas
